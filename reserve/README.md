# Reserve

Færdige opslag, der blev skrevet, men ikke kom i køen. Pipelinen rører dem ikke, fordi den kun læser `queue/`.

Fra uge 47 laver autopiloten klip-reels i stedet for karruseller (se `brand/WEEKLY_PROMPT.md`). Karrusellerne her er sat på pause. Emner og captions må genbruges i klip-reels: skriv 2 til 4 korte linjer til `lines`, vælg `bg` og `stil`, og kør build og tests som normalt.

`2026-W47/` er de 7 karruseller, der var planlagt til uge 47, og som blev erstattet af klip-reels om de samme emner.
